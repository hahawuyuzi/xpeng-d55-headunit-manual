## 几个最关键的结论（浓缩版）

- **D55 无 `aboot` 分区**，bootloader 是 `abl_a/abl_b`；活动槽是 `_b`，刷错槽会直接开不了机。
- **临时 Root 靠原厂 DevTools 命令页注入**，不是 `adb root`（`ro.debuggable=0`，adbd 不能提权）。
- **Magisk 必须修补 `boot_b`**，且 pre-init 存储分区是 `metadata` 而非 D20 的 `persist`。
- **LSPosed 要锁 v1.10.0 (7068)**：v1.11.0 (7209) 的 daemon 在 D55 上必崩，管理器和框架必须同版本。
- **仪表模块任何 hook 异常都不允许抛到宿主**：仪表挂了司机看不到行驶信息，风险比一般 App 高得多。
- **本机 `nohup` 只是 shell 别名**，开机脚本必须用 `setsid`；日志不能写 `/sdcard`（开机早期未挂载）。
